## Deployment (GitHub Pages)

The site files live at the root of the `nyc-acris-records/property-record` repository.

1. Go to **Settings** > **Pages**.
2. Under **Source**, select **Deploy from a branch**.
3. Choose the **main** branch, **/ (root)** folder, and click **Save**.

All URLs in `index.html`, `robots.txt`, `sitemap.xml`, and `404.html` already point to the live site above. If the repository is ever renamed, update those URLs to match.
